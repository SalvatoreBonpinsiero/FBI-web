## 📌 Overview

**FBI-Web** is a lightweight web application that turns a list of entities and their relationships into an interactive, force-directed spider web. It is designed for OSINT analysts, researchers, and students who need a fast, clean way to visualize connections between domains, IPs, emails, usernames, organizations, and people.

Every analysis is exported to a plain-text report — no database, no cloud, no tracking. Everything stays on your machine.

---

## ✨ Features

- 🕸️ **Interactive spider web** — force-directed graph powered by D3.js
- 🎯 **Central target node** — anchored in the middle for clarity
- 🧩 **Typed entities** — domain, IP, email, phone, person, username, org, URL, other
- 🔗 **Custom links** — define relationships between any two entities
- 🖱️ **Drag, zoom, pan** — rearrange the graph in real time
- 📄 **TXT export** — every report is saved to disk and downloadable
- 🎨 **Minimal design** — white background, single yellow accent, Open Sans
- 🔒 **Fully local** — no external APIs, no telemetry, no data leaves your machine
